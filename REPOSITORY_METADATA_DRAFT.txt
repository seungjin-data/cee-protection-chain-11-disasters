Title: Operational conversion of hazard information into human protective action across 11 major disasters
Resource type: Dataset / research data with code
Creator: Seungjin Kim
Description: Coded event-time evidence and reproducibility package for a comparative analysis of the conversion of hazard information into institutional protective action and actual human protective action across 11 major disasters from 2018 to 2025. The package contains event-level and locality-specific analytical matrices, a row-level Ahr evidence matrix, a 185-row source registry, reader-facing table derivatives, Fig. 1 source data and figure-generation code.
